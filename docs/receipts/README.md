# Receipts

Proof for the parts in [`../costs.md`](../costs.md).

- One screenshot or PDF per order.
- The order number and the price have to be visible.
- Crop out the shipping address and the payment details before committing.

Name the file after the date and what's in it, e.g. `2026-10-28-servos.pdf`, and link it from
the Proof file column in `costs.md`. The dashboard only counts a proof file that's actually here.
