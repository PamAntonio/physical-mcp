# Costs

Filled in by hand from receipts and cited sources. `scripts/dashboard_metrics.py` reads the
two tables below, so keep their headers as they are. Add rows freely.

- A part only counts if it has a price **and** a receipt file or order number.
- A comparison only counts if it has a cost **and** a source URL.
- Anything blank stays NEEDS INPUT on the dashboard. Never type an estimate in here.
- Prices in USD, e.g. `12.99` or `$12.99`. Receipt files can go in `docs/receipts/`.
